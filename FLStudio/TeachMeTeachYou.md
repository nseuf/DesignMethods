### Part 1.2
In class I was given a set of instruction on how to draw a face. The five steps simply broke down each part of the process, outlining techniques used to get to realistic proportions for the face. By following these steps I was able to accomplish drawing a face in a semi-realistic way, something I had not been able to do before. The use of the underlying framework to get realistic proportions in the face was a critical aspect I had not thought to use before. It had allowed me to, in a few tries, draw a face. When I had attempted to draw faces in the past they always appeared as cartoonish. I would use some circles to draw the head, eyes, and mouth, without every adding any shading, details, or complexities beyond that. But the guide showed the use of primitive shapes to construct facial features, and simple details that brought the piece together.

 

### Part 2

I have always found DAW's (Digital Audio Workstation) to be very important if I want to do something a bit beyond playing an instrument. It allows me access to instruments I don't know how to play, and the ability to arrange songs how I see fit. In this process I have always used Ableton, it came free with a midi controller I had bought so that became the default. But if I ever wanted more tracks than the provided 10 in the lite version I would have to pay a subscription, and I never liked that idea. So there had always been a desire within me to move towards FL Studio. FL Studio is a competitor to Ableton with more users, a one time purchase model, and lifetime free updates. It is everything I would want in a DAW, except the workflow. I have spent years reinforcing Ableton's workflow into my mind that moving to FL Studio is daunting. But for this assignment my goal is to understand the workflow of the new DAW before class next week.

After messing around in FL Studio for ~1 hour with no external help I have gotten a beat created in the channel rack. I have messed with using different instruments but I don't know how to make anything over 4 bars, which is the default length of the channel rack. So far the workflow for FL is completely different from what I was expecting and how Ableton works. Next, I will do a little research into FL Studio tutorials to see if I can get something longer.

A few more hours have passed since starting FL Studio, I knew DAWs were generally a bit daunting but in my experience once you start using them it makes sense. FL Studio is like that in a way, but the years of Ableton I have to fight is making it harder. The entire workflow of FL is strange, you can't just drop an instrument into a midi channel and start making music. You first have to put it in the channel rack, which gives you access to a sequencer. If you are doing anything but making a drum beat the sequencer seems to be useless, so you have to find the piano roll, which is buried in a menu. Finally in the piano roll you can start arranging the song. It is probably setup like this for a reason, but as someone who doesn't have enough experience in the program to understand the power of it, it seems like an odd design choice. Overall, FL Studio feels counterintuitive at times, but not enough for me to drop it completely. I was able to understand at a very high level the workflow, but it will take tens of hours to start feeling comfortable with it.
